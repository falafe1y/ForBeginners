# Сортировка пузырьком
**Big O** — O(n²)

Алгоритм **сортировки пузырьком** работает путем многократного прохода по массиву и сравнения соседних элементов. Если элементы стоят не в том порядке, их меняют местами. Процесс повторяется до тех пор, пока массив не окажется отсортированным. В худшем и среднем случаях алгоритм имеет квадратичную сложность O(n²), что делает его неэффективным для больших наборов данных. Однако для маленьких массивов или уже частично отсортированных данных сортировка пузырьком может работать вполне нормально.
___
### Плюсы

- Простой и интуитивно понятный алгоритм.
- Легко реализуется.
- Может быть полезен для обучения основам сортировки.

### Минусы:

- Имеет квадратичную сложность (O(n²)), что делает его **неэффективным для больших наборов данных**.
- **Не является стабильным** в случае массива с одинаковыми элементами (хотя можно сделать стабильным с некоторыми улучшениями).
- Требует много времени на выполнение для больших объемов данных по сравнению с другими алгоритмами сортировки, такими как *быстрая* или *слиянием*.

# Объяснение
```cpp
void BubbleSort(vector<int> *arr) {
    int size = arr->size();
    for(int i = 0; i < size - 1; ++i) {
        for(int j = 0; j < size - 1 - i; ++j) {       // the last element already sorted
            if((*arr)[j] > (*arr)[j + 1]) {     // If the current element is larger than the next one, then they are swapped
                swap((*arr)[j], (*arr)[j + 1]);
            }
        }
    }
}
```
Первый цикл `(for(int i = 0; i < size - 1; ++i))` — отвечает за проходы по массиву. Мы будем делать несколько проходов, и каждый проход будет сортировать один элемент, начиная с конца, так как после каждого прохода последний элемент будет находиться на своем месте.

Второй цикл `(for(int j = 0; j < size - 1 - i; ++j))` — этот цикл сравнивает и меняет местами соседние элементы массива. Количество сравнений уменьшается на каждом проходе, потому что элементы в конце уже отсортированы.

Условие `if((*arr)[j] > (*arr)[j + 1])` — если текущий элемент больше следующего, то они меняются местами с помощью `swap((*arr)[j], (*arr)[j + 1])`.

### Пример
Предположим, у нас есть массив:
`[5, 2, 9, 1, 5, 6]`

1. Проход 1:

    - Сравнение 5 и 2: 5 > 2, меняем местами → [2, 5, 9, 1, 5, 6]
    - Сравнение 5 и 9: 5 < 9, оставляем как есть → [2, 5, 9, 1, 5, 6]
    - Сравнение 9 и 1: 9 > 1, меняем местами → [2, 5, 1, 9, 5, 6]
    - Сравнение 9 и 5: 9 > 5, меняем местами → [2, 5, 1, 5, 9, 6]
    - Сравнение 9 и 6: 9 > 6, меняем местами → [2, 5, 1, 5, 6, 9]

После первого прохода последний элемент (9) на своем месте.

2. Проход 2:

    - Сравнение 2 и 5: 2 < 5, оставляем как есть → [2, 5, 1, 5, 6, 9]
    - Сравнение 5 и 1: 5 > 1, меняем местами → [2, 1, 5, 5, 6, 9]
    - Сравнение 5 и 5: 5 = 5, оставляем как есть → [2, 1, 5, 5, 6, 9]
    - Сравнение 5 и 6: 5 < 6, оставляем как есть → [2, 1, 5, 5, 6, 9]

После второго прохода элемент 6 на своем месте.

3. Проход 3:

    - Сравнение 2 и 1: 2 > 1, меняем местами → [1, 2, 5, 5, 6, 9]
    - Сравнение 2 и 5: 2 < 5, оставляем как есть → [1, 2, 5, 5, 6, 9]
    - Сравнение 5 и 5: 5 = 5, оставляем как есть → [1, 2, 5, 5, 6, 9]

Отсортированный массив: `[1, 2, 5, 5, 6, 9]`
