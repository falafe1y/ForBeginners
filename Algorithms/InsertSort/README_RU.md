# Сортировка вставками

**Big O** — O(n²) в худшем случае, O(n) в лучшем случае, если массив уже отсортирован

Сортировка вставками — это алгоритм, который проходит по массиву и постепенно увеличивает отсортированную часть, вставляя текущий элемент в правильное место. Алгоритм напоминает процесс сортировки игральных карт в руке: каждый новый элемент вставляется в уже отсортированную часть массива.
___
### Плюсы

- Эффективен для небольших массивов.
- Простая реализация.
- Подходит для массивов, которые почти отсортированы (время работы близко к O(n)).

### Минусы

- Неэффективен для больших массивов, так как его сложность в худшем случае — O(n²).
- Является нестабильным при реализации, где пересортировка изменяет порядок одинаковых элементов.

# Объяснение
```cpp
void InsertSort(std::vector<int> *arr) {
    // Insert sorting
    for (int currentIndex = 1; currentIndex < arr->size(); ++currentIndex) { 
        int temp = (*arr)[currentIndex];        // The current element
        int sortedIndex = currentIndex - 1;     // Start from the end of the sorted part

        while (sortedIndex >= 0 && (*arr)[sortedIndex] > temp) {
            (*arr)[sortedIndex + 1] = (*arr)[sortedIndex];      // If sortedIndex > temp to, we move sortedIndex to the right
            sortedIndex--;
        }
        (*arr)[sortedIndex + 1] = temp;
    }
}
```

Алгоритм начинает с индекса 1 (`currentIndex = 1`), т.е. со второго элемента, так как массив длины 1 уже отсортирован.

Текущий элемент, который нужно вставить в отсортированную часть, сохраняется в переменной `temp` (`temp = (*arr)[currentIndex]`).

Пока элемент из отсортированной части **больше**, чем `temp`, мы сдвигаем его вправо.

Когда находим подходящее место, вставляем `temp` обратно в массив.

### Пример
Исходный массив:
`[8, 4, 6, 2, 9]`

Шаги алгоритма:

1. `currentIndex = 1, temp = 4`
    - Отсортированная часть: [8]
        - Сравниваем 8 > 4, сдвигаем 8 вправо.
        - Вставляем 4.
        - Текущее состояние: [4, 8, 6, 2, 9].

2. `currentIndex = 2, temp = 6`
    - Отсортированная часть: [4, 8]
        - Сравниваем 8 > 6, сдвигаем 8 вправо.
        - Вставляем 6.
        - Текущее состояние: [4, 6, 8, 2, 9].

3. `currentIndex = 3, temp = 2`
    - Отсортированная часть: [4, 6, 8]
        - Сравниваем 8 > 2, сдвигаем 8 вправо.
        - Сравниваем 6 > 2, сдвигаем 6 вправо.
        - Сравниваем 4 > 2, сдвигаем 4 вправо.
        - Вставляем 2.
        - Текущее состояние: [2, 4, 6, 8, 9].

4. `currentIndex = 4, temp = 9`
    - Отсортированная часть: [2, 4, 6, 8]
        - Сравниваем 8 < 9. Элемент уже на своем месте.
        - Текущее состояние: [2, 4, 6, 8, 9].

Итог:

Отсортированный массив:
`[2, 4, 6, 8, 9]`
