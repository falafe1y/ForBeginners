# Сортировка подсчетом
**Big O** — O(n + k)

Алгоритм **сортировки подсчетом** работает путем подсчета количества вхождений каждого уникального элемента в массив. Для этого создается вспомогательный массив, в котором индекс соответствует элементу из исходного массива, а значение в этом индексе — количество вхождений этого элемента. Затем элементы исходного массива восстанавливаются в отсортированном порядке, используя этот вспомогательный массив. Время работы алгоритма зависит от размера массива и величины максимального элемента (k), что делает его линейным при ограниченном диапазоне значений.
___
### Плюсы

- Быстро работает при ограниченном диапазоне значений элементов.
- Алгоритм имеет линейную сложность O(n + k), что делает его эффективным для больших наборов данных с небольшими значениями.
- Не требует дополнительной памяти для рекурсии, как например, в алгоритмах слияния.

### Минусы:
- Не работает с данными, содержащими отрицательные числа или значения с плавающей точкой (хотя можно адаптировать для этих случаев).
- Требует значительного объема дополнительной памяти для хранения счетчиков, особенно при больших значениях элементов.
- Не подходит для общих случаев, где элементы имеют широкий диапазон значений.

# Объяснение
```cpp
void CountingSort(std::vector<int> *arr) {
    if (arr->empty()) return;
    int maxElement = *max_element(arr->begin(), arr->end());

    // Create a vector of size maxElement + 1, 
    // where all elements are 0
    std::vector<int> count(maxElement + 1, 0);

    for (int num : *arr) {
        count[num]++;
    }

    int index = 0;
    for (int i = 0; i <= maxElement; ++i) {
        std::cout << "Itteration №" << i+1 << ": ";
        while (count[i] > 0) {
            (*arr)[index++] = i;
            count[i]--;
        }
    }
}
```
Проверка на пустоту массива `(if (arr->empty()) return;)` — если массив пуст, то функция сразу завершится, так как нечего сортировать.

Поиск максимального элемента массива `(int maxElement = *max_element(arr->begin(), arr->end());)` — для определения размера вспомогательного массива count необходимо найти максимальный элемент в исходном массиве, так как диапазон значений, которые нам нужно учитывать, ограничен этим элементом.

Создание массива подсчета частоты элементов `(std::vector<int> count(maxElement + 1, 0);)` — создается вспомогательный массив count, в котором каждый индекс соответствует элементу из массива arr, а значение в этом индексе — количество вхождений этого элемента в массиве.

Подсчет частоты каждого элемента `(for (int num : *arr) { count[num]++; })` — каждый элемент массива arr инкрементирует соответствующий индекс в массиве count, таким образом создается частотное распределение элементов.

Восстановление отсортированного массива `(for (int i = 0; i <= maxElement; ++i) {...})` — начиная с нулевого индекса, мы проходим по массиву count и восстанавливаем элементы исходного массива, заполняя их в порядке возрастания. Для каждого значения индекса (которое является элементом массива `arr`) мы добавляем его в итоговый массив столько раз, сколько раз оно встречается (согласно значению в `count[i]`).
___
### Пример
Предположим, у нас есть массив:
`[5, 2, 9, 1, 5, 6]`

1. Шаг 1: Найдем максимальный элемент

    Максимальный элемент массива = 9.
    
2. Шаг 2: Создаем массив подсчета

    Массив подсчета:
[0, 1, 1, 0, 0, 2, 1, 0, 0, 1]

    - Индекс 0: 0 элементов.
    - Индекс 1: 1 элемент (1 встречается 1 раз).
    - Индекс 2: 1 элемент (2 встречается 1 раз).
    - Индекс 5: 2 элемента (5 встречается 2 раза).
    - Индекс 6: 1 элемент (6 встречается 1 раз).
    - Индекс 9: 1 элемент (9 встречается 1 раз).

3. Шаг 3: Восстановление отсортированного массива

    1. Первая итерация (i = 0): массив не изменяется, так как в массиве нет нулей.
    2. Вторая итерация (i = 1): вставляем 1 → [1, 2, 9, 1, 5, 6]
    3. Третья итерация (i = 2): вставляем 2 → [1, 2, 9, 1, 5, 6]
    4. Четвертая итерация (i = 5): вставляем дважды 5 → [1, 2, 5, 5, 6, 9]
    5. Пятая итерация (i = 6): вставляем 6 → [1, 2, 5, 5, 6, 9]
    6. Шестая итерация (i = 9): вставляем 9 → [1, 2, 5, 5, 6, 9]

Итог:

Отсортированный массив: `[1, 2, 5, 5, 6, 9]`
