## Теория

Существует два типа куч - **максимальная** и **минимальная**
Различия:

|**Характеристика**|**Макс-куча**|**Мин-куча**|
|---|---|---|
|**Свойство**|Родитель ≥ Потомки|Родитель ≤ Потомки|
| **Вершина кучи** | Максимальный элемент | Минимальный элемент |
| **Использование** | Приоритетные очереди, поиск максимума | Приоритетные очереди, поиск минимума |
| **Операции добавления и удаления** | Предоставляет поиск максимума | Предоставляет поиск минимума |

### **Используется для реализации**:

|**Приложения**|**Макс-куча**|**Мин-куча**|
|---|---|---|
|Очереди приоритетов|Наивысший приоритет|Наименьший приоритет|
|Алгоритмы графов|Крускал, Прим|Дейкстра, Прим|
|Сортировка|По убыванию|По возрастанию|
|Выбор *K* лучших/худших элементов|*K* наибольших элементов|*K* наименьших элементов|
|Потоковые данные|Максимальное значение в потоке|Минимальное значение в потоке|

## Различия между кучей и деревом
Дерево и куча — это структуры данных, которые часто путают из-за их схожести, но у них есть фундаментальные различия. Давайте проанализируем их по ключевым параметрам:

- **Дерево** — это иерархическая структура, в которой каждый узел может иметь произвольное количество потомков.

- Его узлы могут располагаться на любом уровне, без строгих правил заполнения.
- Он используется для представления отношений, в которых узлы связаны в соответствии с их иерархией (например, файловая система).

- **Куча** - это частный случай дерева, причем строго двоичного дерева.

- Куча заполняется слева направо, уровень за уровнем. Последний уровень может быть неполным, но его элементы находятся строго слева.
- Она разработана для эффективной работы с минимальными или максимальными элементами.
- Извлечение минимального (или максимального) элемента занимает постоянное время.

|**Операция**|**Дерево (BST)**|**Куча**|
|---|---|---|
|**Поиск элемента**|*O(log⁡N)* (в B-дереве)|*O(N)*|
|**Добавление элемента**|*O(log⁡N)*|*O(logN)*|
|**Удаление элемента**|*O(log⁡N)*|*O(logN)* (удаление корня)|
|**Доступ к корню**|*O(log⁡N)* (может быть не самым большим/наименьшим)|*O(1)* (корень — это мин/макс)|

Если представить кучу как дерево, то это может выглядеть так:

                                            1
                                           / \
                                          2   3
                                         / \   \
                                        4   5   6

Интересно, что обход такой кучи будет идентичен обходу двоичного дерева с использованием метода BFS.

```cpp
void MaxHeap::heapifyUp(int index) {
    while (index > 0) {
        int parent = (index - 1) / 2;
        if (heap[index] > heap[parent]) {
            std::swap(heap[index], heap[parent]);
            index = parent;
        } else {
            break;
        }
    }
}
```
`while (index > 0)` цикл продолжается до тех пор, пока текущий узел не достигнет корня или его позиции (index = 0).

`int parent = (index - 1) / 2;` в этой строке мы находим родителя, используя формулу *(index - 1) / 2*. Для узла с индексом = 5: `parent = (5 - 1) / 2 = 2`.

```cpp
if (heap[index] > heap[parent]) {
    std::swap(heap[index], heap[parent]);
    index = parent;
}
```
Если текущий узел больше своего родителя, мы меняем их местами и устанавливаем `index` в `parent`. То же самое верно для **минимальной** кучи, но знак меняется на **противоположный**:
```cpp
if (heap[index] < heap[parent])
```
На самом деле, единственное различие между этими двумя классами заключается в этой строке и похожей в методе `heapifyDown`.
### Пример
Исходная куча: [50, 30, 20, 15, 10, 8, 5]

Добавляем элемент 40. Теперь куча: [50, 30, 20, 15, 10, 8, 5, 40].
Метод heapifyUp начал работать:

1. index=7, parent: (7−1)/2=3. Сравниваем 40 и 15:
40 > 15, меняем их местами.
Массив: [50, 30, 20, 40, 10, 8, 5, 15].
индекс = 3.

2. индекс = 3, родитель: (3−1)/2=1. Сравниваем 40 и 30:
40 > 30, меняем их местами.
Массив: [50, 40, 20, 30, 10, 8, 5, 15].
индекс = 1.

3. индекс = 1, родитель: (1−1)/2=0. Сравниваем 40 и 50:
40 ≤ 50, цикл заканчивается.

Полученная куча: [50, 40, 20, 30, 10, 8, 5, 15]

### Является ли полученная куча допустимой?
Да, потому что куча — это **неупорядоченный** массив в общем смысле. Его действительность определяется двумя правилами:
- **Свойство Max/Min Heap**:

В максимальной куче значение любого узла должно быть больше или равно значению его дочерних элементов (если таковые имеются).

В минимальной куче значение любого узла должно быть меньше или равно значению его дочерних элементов.

- **Свойство Complete:**

Куча должна быть полным двоичным деревом, заполняющим уровни слева направо без пробелов.
___
```cpp
void MaxHeap::heapifyDown(int index) {
    int size = heap.size();
    while (index < size) {
        int left = 2 * index + 1;
        int right = 2 * index + 2;
        int largest = index;

        if (left < size && heap[left] > heap[largest]) {
            largest = left;
        }
        if (right < size && heap[right] > heap[largest]) {
            largest = right;
        }
        if (largest != index) {
            std::swap(heap[index], heap[largest]);
            index = largest;
        } else {
            break;
        }
    }
}
```
используется для восстановления свойства MaxHeap при перемещении узла вниз по дереву. Это может понадобиться, например, после извлечения максимального элемента из корня (extractMax), когда последний элемент заменяет корень, но может нарушить свойство кучи.

Далее вычисляются индексы левого `(2 * index + 1)` и правого `(2 * index + 2)` потомков.

Далее мы ищем самый большой узел. В самом начале мы берем текущий узел как самый большой. Затем мы смотрим, больше ли левый или правый потомок нашего самого большого узла. Если одно из условий истинно, мы устанавливаем самый большой узел на тот, который мы только что нашли.

```cpp
if (largest != index) {
    std::swap(heap[index], heap[largest]);
    index = largest;
}
```

Условие проверяет, изменился ли индекс самого большого узла.
В начале итерации предполагается, что текущий узел (индекс) является наибольшим.
Однако, если левый или правый дочерний узел больше текущего узла, то обновляется наибольшая переменная (в коде выше).

Если largest != index, это означает, что у текущего узла есть дочерний узел, который больше его. В этом случае вам нужно исправить ситуацию, чтобы восстановить свойство MaxHeap.

### Пример
Допустим, у нас есть куча, например, такая: [5, 10, 20, 30, 15, 8, 40]

Это недопустимая MaxHeap, так как корень 5 меньше дочерних узлов. Нам нужно восстановить свойство кучи с помощью `heapifyDown(0)`.

1. индекс = 0, куча[0] = 5.

Левый потомок: куча[1] = 10, правый потомок: куча[2] = 20.

Самый большой узел: куча[2] = 20.

Обмен: std::swap(heap[0], heap[2]).

Куча: [20, 10, 5, 30, 15, 8, 40].

Новый индекс = 2.

2. индекс = 2, куча[2] = 5.

Левый потомок: куча[5] = 8, правый потомок: куча[6] = 40.

Самый большой узел: куча[6] = 40.

Обмен: std::swap(heap[2], heap[6]).

Куча: [20, 10, 40, 30, 15, 8, 5].

Новый индекс = 6.

3. индекс = 6, куча[6] = 5.

Дочерних элементов нет, так как left = 13, right = 14 выходят за пределы размера массива.

Завершить цикл.

Конечная куча: [20, 10, 40, 30, 15, 8, 5]
___
```cpp
void MaxHeap::insert(int value) {
    heap.push_back(value);
    heapifyUp(heap.size() - 1);
}
```
Новый элемент добавляется в конец кучи (в нижнюю правую позицию дерева). Далее выполняется "просеивание вверх":
- Сравниваем новый элемент с его родителем.
- Если новый элемент больше родителя, они меняются местами.
- Повторяем до тех пор, пока не будет восстановлено свойство кучи (или пока не достигнем корня).

### Пример
Пусть изначально кучу представляет массив: `[50, 30, 20, 15, 10, 8, 16]`.

Добавляем значение 60:

- После `push_back`: `[50, 30, 20, 15, 10, 8, 16, 60]`.
- Просеивание вверх (heapifyUp):
    - 60 > 15, меняем местами: `[50, 30, 20, 60, 10, 8, 16, 15]`.
    - 60 > 30, меняем местами: `[50, 60, 20, 30, 10, 8, 16, 15]`.
    - 60 > 50, меняем местами: `[60, 50, 20, 30, 10, 8, 16, 15]`.

Итоговая куча: `[60, 50, 20, 30, 10, 8, 16, 15]`.

Для минимальной кучи все то же самое, но "просеивание" будет вниз.
___
```cpp
int MaxHeap::extractMax() {
    if (heap.empty()) {
        throw std::runtime_error("Heap is empty");
    }
    int maxValue = heap[0];
    heap[0] = heap.back();
    heap.pop_back();
    heapifyDown(0);
    return maxValue;
}
```
Проверяем не пуста ли куча. Если так, то так об этом и говорим.

В ином случае сохраняем максимальный (корневой) элемент кучи, перемещаем последний элемент в корень и удаляем последний элемент. После просеиваем вниз (`heapifyDown`)

### Пример

Куча: `[60, 50, 20, 30, 10, 8, 16, 15]`.

- Сохраняем 60.
- Перемещаем 15 в корень: `[15, 50, 20, 30, 10, 8, 16]`.
- "Просеивание вниз":
    - 15 < 50, меняем местами: `[50, 15, 20, 30, 10, 8, 16]`.
    - 15 < 30, меняем местами: `[50, 30, 20, 15, 10, 8, 16]`.

Итог: `[50, 30, 20, 15, 10, 8, 16]`. Возвращаемое значение: 60.
