# Двоичное дерево
- [ ] Закончено?

## Теория

Почему **двоичное** дерево? Узел в таком дереве может иметь только **два** потомка — левого и правого.

**Используется для реализации**:
- Поиска и сортировки
- Хранения структур данных
- Представления выражений
- Компьютерной графики
- Систем управления базами данных
- Сжатия данных, например ZIP и JPEG
- Игр и ИИ

Дерево можно представить примерно так:

                                            1
                                           / \
                                          2   3
                                         / \   \
                                        7   8   9

# Объяснение

Здесь будут обсуждаться **приватные** методы. Подробно объяснять публичные методы нет смысла, поскольку они служат обычными **интерфейсами**.

```cpp
class BinaryTree {
    struct Node {
    int data;
    Node* left;
    Node* right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};
```

Это вложенная структура узла. Мы уже видели этот механизм языка в реализации **стека**.

# Обход дерева
В качестве примера возьмем следующее дерево:

                                            A
                                           / \
                                          B   C
                                         / \   \
                                        D   E   F

## DFS
### Обход в прямом порядке (симметричный)
Порядок обхода: левый подузел → корень → правый подузел

Шаги:
- Начать с корня (A).
- Перейти в левое поддерево (B).
- Перейти в левое поддерево (D). Распечатать D.
- Вернуться в B. Распечатать B.
- Перейти в правое поддерево (E). Распечатать E.
- Вернуться в A. Распечатать A.
- Перейти в правое поддерево (C).
- Перейти в правое поддерево (F). Распечатать F.

Результат: D, B, E, A, C, F

### Прямой (прямой) обход

Порядок обхода: корень → левый подузел → правый подузел

Шаги:

- Начать с корня (A). Распечатать A.
- Перейти в левое поддерево (B). Распечатать B.
- Перейти в левое поддерево (D). Распечатать D.
- Вернуться в B и перейти в правое поддерево (E). Распечатать E.
- Вернуться в A и перейти в правое поддерево (C). Распечатать C.
- Перейти в правое поддерево (F). Распечатать F.

Результат: A, B, D, E, C, F

### Обход в обратном порядке

Порядок обхода: Левый подузел → Правый подузел → Корень

Шаги:

- Начать с корня (A) и перейти в левое поддерево (B).
- Перейти в левое поддерево (D). Распечатать D.
- Вернуться в B и перейти в правое поддерево (E). Распечатать E.
- Вернуться в B. Распечатать B.
- Вернуться в A и перейти в правое поддерево (C). Распечатать C.
- Перейти в правое поддерево (F). Печать F.
- Возврат к C. Печать C.
- Возврат к A. Печать A.

Результат: D, E, B, F, C, A

## BFS (поиск в ширину)

                                            A
                                           / \
                                          B   C
                                         / \   \
                                        D   E   F

Порядок обхода: сначала посетить корень, затем все узлы на первом уровне, затем на втором уровне и т. д.

Шаги:
- Начать с корня (A) и поместить его в очередь.
- Извлечь A из очереди и распечатать его.
- Добавить всех дочерних элементов A (B и C) в очередь.
- Извлечь B из очереди и распечатать его.
- Добавить всех дочерних элементов B (D и E) в очередь.
- Извлечь C из очереди и распечатать его.
- Добавить дочерний элемент C (F) в очередь.
- Извлечь D из очереди и распечатать его. (У D нет дочерних элементов)
- Извлечь E из очереди и распечатать его. (У E нет дочерних элементов)
- Извлечь F из очереди и распечатать его. (У F нет детей)

Результат: A, B, C, D, E, F
