# Хэш-таблица
- [ ] Закончено?
## Теория 
**Хэш-таблица** — это структура данных, которая позволяет эффективно хранить и извлекать данные за время, близкое к *O(1)*. Она широко используется для реализации ассоциативных массивов, когда элементы хранятся в виде пар "ключ-значение".

Основная идея хэш-таблицы заключается в использовании хэш-функции, которая преобразует ключ в индекс для доступа к массиву, где хранятся значения.

**Где используется?**:

- Ассоциативные массивы и контейнеры
- Кэширование
- Базы данных
- Компиляторы (таблицы символов)
- Системы распределенных вычислений
- Криптография
- Системы управления памятью
- Игровые движки
- Big Data

# Объяснение
**Методы**:
- insert - вставить новую пару "ключ-значение"
- search - вернуть bool, сообщающий есть ли такая пара в таблице
- remove - удалить пару
- print - напечатать таблицу
- size - вернуть размер таблицы
___
```cpp
void insert(const K& key, const V& value) {
    size_t index = hash(key);
    for (auto& pair : table[index]) {
        if (pair.first == key) {
            pair.second = value;
            return;
        }
    }
    table[index].emplace_back(key, value);
}
```
Если ключ уже существует, значение обновляется.

### Пример

Начальное состояние таблицы: пустая.

Вставим следующие пары: `(1, "Alice")`, `(6, "Bob")`, `(3, "Eve")`.

- Для ключа 1:
    - Хэш: 1 % 5 = 1.
    - Ищем в `table[1]` (список на индексе 1) — список пуст.
    - Добавляем пару `(1, "Alice")` в `table[1]`.

- Для ключа 6:
    - Хэш: 6 % 5 = 1.
    - Ищем в `table[1]` — там уже есть `(1, "Alice")`.
    - Так как ключи разные, добавляем пару `(6, "Bob")` в `table[1]` (коллизия разрешается через цепочку).

- Для ключа 3:
    - Хэш: 3 % 5 = 3.
    - Список `table[3]` пуст. Добавляем пару `(3, "Eve")`.

Результат таблицы:
```
Index 0: 
Index 1: (1, Alice) (6, Bob)
Index 2: 
Index 3: (3, Eve)
Index 4:
```
**P. s.** Каждая ячейка таблицы (индекс) представлена контейнером типа `std::list`. Если в конкретной ячейке не было добавлено элементов, то этот список остаётся пустым, но это не значит, что "пустые" индексы (0, 2, 4) вообще отсутствуют — они есть, просто содержат пустые списки.
___
```cpp
bool search(const K& key, V& value) const {
    size_t index = hash(key);
    for (const auto& pair : table[index]) {
        if (pair.first == key) {
            value = pair.second;
            return true;
        }
    }
    return false;
}
```
Сначала вычисляем индекс через хэш-функцию и проходим все пары в списке по индексу. Если пара найдена - возвращается `true`, иначе `false`.
### Пример
Имеем:
```
Index 0: 
Index 1: (1, Alice) (6, Bob)
Index 2: 
Index 3: (3, Eve)
Index 4: 
```
Найдем значение для ключа 1.

- Входные данные:

    - Ключ для поиска: 1.
    - Хэш-таблица уже содержит данные.
    - Хэш-функция:
    ```cpp
    size_t hash(const int& key) const {
        return key % table_size; // table_size = 5
    }
    ```

- Вычисление хэша:

    - Хэш для ключа 1:

    - `size_t index = hash(1); // 1 % 5 = 1`

    - Получаем индекс 1.

- Поиск в списке на индексе 1:

    - Смотрим на `table[1]`:

    - `table[1]`: `[(1, "Alice"), (6, "Bob")]`

    - Начинаем обход элементов списка:
        - Первая пара: `(1, "Alice")`.
        - Ключ совпадает (1 == 1).
            - Сохраняем значение `"Alice"` в `value`.
            - Возвращаем `true` (поиск успешен).

- Результат поиска:

    - Метод возвращает `true`.
    - Значение ключа 1: `"Alice"`.
___
```cpp
bool remove(const K& key) {
    size_t index = hash(key);
    auto& list = table[index];
    for (auto it = list.begin(); it != list.end(); ++it) {
        if (it->first == key) {
            list.erase(it); // Remove pair
            return true;
        }
    }
    return false;
}
```
Вычисляем индекс по ключу, получаем список по индексу и обходим всех элементов из полученного списка. Далее проверяем ключи на совпадение с `key` (`it->first` хранит ключ элемента, который мы проверяем в данный момент). Если ключи совпали - удаляем эту пару и возвращаем 'true'.
### Пример
1. Шаг 1:
    Метод вычисляет индекс ячейки таблицы для данного ключа, используя хэш-функцию:

    `size_t index = hash(key);`

    Это позволяет нам найти, в какой ячейке находится список пар (ключ, значение).

2. Шаг 2:
    Получаем ссылку на список пар, расположенных в ячейке с найденным индексом:

    `auto& list = table[index];`

    Теперь мы имеем доступ к списку всех элементов с этим индексом.

3. Шаг 3:
    Идем по списку с помощью итератора:

    `for (auto it = list.begin(); it != list.end(); ++it)`

    Проходим по всем парам (ключ, значение) в этой ячейке.

4. Шаг 4:
    Сравниваем ключ текущей пары с переданным ключом:

    `if (it->first == key)`

    Если ключ совпадает, то нашли элемент, который нужно удалить.

5. Шаг 5:
    Удаляем найденный элемент из списка:

    `list.erase(it);`

    Метод erase удаляет пару по итератору `it`.

6. Шаг 6:
    После успешного удаления возвращаем `true`, чтобы указать, что элемент был найден и удален.

7. Шаг 7:
    Если ключ не найден в списке, возвращаем `false`.
