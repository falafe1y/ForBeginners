# Вектор
Вектор (Vector) — это контейнер, который представляет собой динамический массив. Он позволяет хранить элементы и управлять ими. Скорость доступа к элементам составляет *O(1)*, так как данные находятся в непрерывной области памяти. Реализация вектора должна подразумевать автоматическое выделение памяти под новые данные, а так же очищение памяти удаленных объектов, дабы не создавать утечек.

**Где используется?**:

- Векторная графика
- Рассчеты для математики и физики
- Игровая индустрия (оптимизация)
- Машинное обучение

# Объяснение
**Методы**:
 - push_back - добавить элемент в конец вектора
 - pop_back - удалить последний элемент
 - size - вернуть размер вектора (сколько элементов прямо сейчас включены в вектор)
 - capacity - вернуть вместимость вектора
 - clear - очистить содержимое вектора
___
```cpp
T& operator[](size_t index) {
    if (index >= vec_size) {
        throw std::out_of_range("Index out of range.");
    }
    return data[index];
}

const T& operator[](size_t index) const {
    if (index >= vec_size) {
        throw std::out_of_range("Index out of range.");
    }
    return data[index];
}
```
Это два перегруженных оператора `[]`, позволяющие обращаться к элементам вектора через их индексы.
___
```cpp
// Increases the array capacity
void resizeCapacity(size_t new_capacity) {
    T* new_data = new T[new_capacity]; // New array
    for (size_t i = 0; i < vec_size; ++i) {
        new_data[i] = data[i]; // Copy old data
    }
    delete[] data; // Free the old memory
    data = new_data; // Pointer to the new array
    vec_capacity = new_capacity;
}
```
Приватный метод, изменяющий текущий размер вектора.

Сначала мы создаем новый динамический массив с размером `new_capacity`, который был передан как аргумент. Далее в цикле от 0 до размера вектора мы компируем каждый элемент из уже существующего динамического массива в только что созданный, не нарушая относительный порядок.

Существует так же метод расширения вектора без копирования данных, но об этом позже.
___
```cpp
// Adds an element to the end
void push_back(const T& value) {
    if (vec_size == vec_capacity) {
        size_t new_capacity = (vec_capacity == 0) ? 1 : vec_capacity * 2;
        resizeCapacity(new_capacity);
    }
    data[vec_size++] = value;
}
```
Передаем значение типа `T`, т.е. шаблонное, любое. Проверяем соответствует ли размер вектора значению его вместимости. Если да, значит вектор заполнен и его размер нужно обновить.

Проверяем, не пуст ли вектор. Если да - его размер будет 1, если нет, то текущий размер умножаем на 2. Далее выделяем новую память, равную `new_capacity` и присваиваем элементу, который больше текущего размера вектора на 1 наше значение `value`.

Объясню последнюю строку подробнее. Текущий размер = 10 и вместимость тоже 10. Мы удваиваем вместимость и создаем память под нее. Теперь размер = 10, а вместимость = 20. Теперь обращаемся к элементу под индексом 10++, т.е. 11. Там и будет храниться переданное в `push_back` значение.

P.s. cтрока `size_t new_capacity = (vec_capacity == 0) ? 1 : vec_capacity * 2;` работает по формуле `условие ? делать_если_истина : делать_если_ложь;`
___
```cpp
// Removes the last element
void pop_back() {
    if (vec_size > 0) {
        --vec_size;
    } else {
        throw std::underflow_error("Vector is empty, cannot pop_back.");
    }
}
```
Тут все просто - если размер вектора не 0, то просто уменьшаем его на единицу. Все, что за границами динамического массива, который является основой вектора, будет автоматически удалено. Иначе бросаем исключение.
