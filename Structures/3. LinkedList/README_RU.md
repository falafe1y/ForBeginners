# Связный список
- [ ] Закончено?
## Теория
Связный список — это структура данных, состоящая из узлов, где каждый из них содержит **данные** и **указатель на следующий узел** (или несколько указателей в случае двусвязного списка). В памяти такая структура хранится хаотично. Связный список не требует, чтобы узлы находились в соседних ячейках памяти. В этом есть и плюсы, и минусы.

Существует 3 вида связных списков:
- Односвязный список - каждый узел хранит **указатель только на следующий узел**, навигация возможна **только в одном направлении**.
- Двусвязный список - каждый узел содержит **два указателя**: на следующий узел и на предыдущий. Навигация возможна в обоих направлениях.
- Кольцевой список - **последний узел в списке указывает на первый**, образуя кольцо. Может быть как односвязным, так и двусвязным.

### **Плюсы и минусы использования связного списка**:
|**Преимущества**|**Недостатки**|
|---|---|
|Добавление или удаление элемента в начале списка выполняется за **O(1)**.| Для получения элемента по индексу нужно последовательно проходить список от начала до нужного узла O(n).|
|Элементы добавляются и удаляются без необходимости перераспределения памяти..| Дополнительная память расходуется на хранение указателей.|

### **Где используется?**:
- Буферы обработки данных
- Очереди сообщений
- STL C++ в `std::list`
- Система крафта в играх
- Блокчейн
- Пропущенные структуры данных (Skip List)
- Кольцевые буферы
- Связанные деревья:
- Управление текстовыми редакторами (представление строк текста, упрощенная работа с ним)
- Аллокаторы памяти (например, malloc в C)
- Графы
- В операционных системах:
    - Таблицы открытых файлов (File Descriptor Table): Файлы, открытые процессами, могут храниться в связном списке.
    - Управление задачами: Односвязные или двусвязные списки используются для реализации очередей задач.

# Объяснение
**Методы**:
- push_front — добавляет элемент в начало списка.
- push_back — добавляет элемент в конец списка.
- pop_front — удаляет первый элемент из списка.
- clear — удаляет все элементы из списка, освобождая память.
- print — выводит содержимое списка в консоль.
- get_size — возвращает количество элементов в списке.
- is_empty — проверяет, пуст ли список.
___
```cpp
struct Node {
    T data;
    Node* next;

    Node(const T& value) : data(value), next(nullptr) {}
};

Node* head; // Pointer to begin of list
size_t size; // Size of list
```
`Node` - это приватная подструктура класса `LinkedList`, реализующая узел в связном списке.
___
```cpp
void push_front(const T& value) {
    Node* newNode = new Node(value);
    newNode->next = head;
    head = newNode;
    size++;
}
```
Проще объяснить на примере.

P.s. важное уточнение, чтобы никто не путался: связный список читается слева-направо, соответственно и "голова" - самый левый элемент.

### Пример

Предположим, что у нас есть список:
```
    10 -> 20 -> 30
    |
   HEAD
```
и мы добавляем новый элемент 5 с помощью `push_front(5)`.
Мы создаём новый узел `newNode` с данными 5. Он пока не связан с другими узлами.

Теперь мы делаем так:
```cpp
newNode->next = head;   // Новый элемент теперь указывает на старую голову (на 10)
```

Это связывает новый элемент с текущим первым элементом списка.

Далее обновляем head, чтобы он теперь указывал на новый элемент:
```
head = newNode; // Голова теперь указывает на новый элемент (на 5)
```
Теперь структура списка будет такая:
```
    5 -> 10 -> 20 -> 30
    |
   HEAD
```
___
```cpp
void push_back(const T& value) {
    Node* newNode = new Node(value);
    if (!head) {
        head = newNode;
    } else {
        Node* temp = head;
        while (temp->next) {
            temp = temp->next;
        }
        temp->next = newNode;
    }
    size++;
}   
```
Этот метод добавляет элемент в **конец** связного списка, т.е. как можно **правее**. Если метод `push_front` добавлял элемент как можно **левее**, то этот работает **наоборот**.

И так, создаем `newNode`, проверяем пуст ли связный список (`if (!head)`). Если пуст, то головой становится только что созданный узел. Если список **не пуст**, то:
- Мы начинаем с головы списка (`temp = head`).
- Далее в цикле while (`temp->next`) мы идём по списку до тех пор, пока не найдём последний элемент. У последнего элемента поле `next` будет равно `nullptr`.
- Когда цикл заканчивается, `temp` указывает на последний элемент списка.
- Мы добавляем новый элемент в конец списка, устанавливая у последнего элемента `temp->next` указатель на новый узел `newNode`.

После мы увеличиваем размер связного списка. 
### Пример
Предположим, что у нас есть пустой список, и мы добавляем несколько элементов.

1. - Первый вызов `push_back(10)`:
        - Новый узел newNode создается с данными 10.
        - Список пуст, поэтому head будет указывать на новый узел.
        - Список теперь:

    `10 -> nullptr`

2. - Второй вызов `push_back(20)`:

        - Новый узел newNode создаётся с данными 20.
        - Список не пуст, поэтому начинаем с головы списка.
        - Мы видим, что следующий элемент у головы (head) равен nullptr, значит, это последний элемент.
        - Устанавливаем temp->next = newNode, чтобы последний элемент указывал на новый узел.
        - Список теперь:

    `10 -> 20 -> nullptr`

3. - Третий вызов `push_back(30)`:

        - Новый узел newNode создаётся с данными 30.
        - Снова проходим по списку, начиная с головы, и находим последний элемент (20).
        - Устанавливаем temp->next = newNode, чтобы последний элемент указывал на новый узел.
        - Список теперь:

    `10 -> 20 -> 30 -> nullptr`
___
```cpp
void pop_front() {
    if (!head) return;

    Node* temp = head;
    head = head->next;
    delete temp;
    size--;
}
```
Метод для удаления самого **левого** элемента, т.е. *головы*. Проверяем существует ли `head`. Если нет, ничего и не возвращаем. Иначе создаем временный узел `temp`, указывающий на текущую голову. После переназначаем указатель головы с самого первого, на следующий - второй - элемент списка.

### Пример

Имеем такой список:
```cpp
    1 -> 2 -> 3 -> nullptr
    |
   HEAD
```
Голова есть, поэтому не будем переходим к созданию фиктивного узла. Срабатывают строки
```cpp
Node* temp = head;
head = head->next;
```
Таким образом имеем
```cpp
*1* -> 2 -> 3 -> nullptr
       |
      HEAD 
```
Фиктивный узел здесь изображен как `*1*`. Теперь удаляем фиктивный узел, чтобы он не занимал место в памяти и уменьшаем размер списка:
```cpp
delete temp;
size--;
```
Таким образом мы по факту удалили голову, которая являлась текущей до вызова этого метода.
___
```cpp
void clear() {
    while (head) {
        pop_front();
    }
}
```
Пока существует голова вызываем метод `pop_front`.

### Пример
Список:
```cpp
    1 -> 2 -> 3 -> nullptr
    |
   HEAD
```

Удаленные элементы будут в квадратных скобках `[]`.

1. Первый вызов. Голова - `1`
    ```cpp
    [1] -> 2 -> 3 -> nullptr
           |
          HEAD
    ```

2. Второй вызов. Голова - `2`
    ```cpp
    [1] -> [2] -> 3 -> nullptr
                  |
                 HEAD
    ```

3. Третий вызов. Голова - `3`
    ```cpp
    [1] -> [2] -> [3] -> nullptr
                            |
                           HEAD
    ```

Теперь голова - nullptr, а значит связный список пуст.
