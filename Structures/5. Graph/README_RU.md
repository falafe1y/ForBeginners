# Граф
- [ ] Закончено?
## Теория
Граф - фундаментальная структура данных, широко используемая во многих сферах нашей жизни. Структура данных графа представляет собой набор узлов, которые имеют данные и связаны с другими узлами. 

Граф может быть:
- **Неориентированным**. Ребра не имеют направления, можно свободно перемещаться в обе стороны от любого графа к любому другому.
    ```
    1 — 2
     \
      3
    ```
    Здесь можно перейти от 1 к 2 и обратно, а также от 1 к 3 и обратно.
- **Ориентированным**. У ребер есть направления.
    ```
    1 → 2
     ↘  
       3
    ```
    Здесь можно перейти от 1 к 2 и от 1 к 3, но не обратно.
- **Двунаправленным**. Это частный случай ориентированного графа, в котором для каждого направленного ребра u -> v существует обратное ребро v -> u.
    ```
    1 ↔ 2
     ↔  
      3
    ``` 
    Здесь между всеми вершинами можно перемещаться в обоих направлениях.
- **Односторонним**. Это частный случай ориентированного графа, в котором между двумя вершинами может быть только одно направление.
    ```    
        A
       ↙ ↘
      B   C
       ↘   ↘
         D → E
    ```
    В таком графе можно перемещаться только в указанных направлениях. К примеру, A - C - E, но никак не E - C - A.

Можно заметить, что **двунаправленный** и **неориентированный** графы очень похожи. Это так и по факту единственное различие между ними - способ хранения связи между двумя вершинами в памяти.
- Неориентированный граф хранит ребро между `A` и `B` как (A, B).
- Двунаправленный записывает точно такое же ребро как два разных, по одному на каждое направление - (A, B), (B, A).

**Рассмотрим на примере**:
На facebook все является узлом. Сюда входят пользователь, фотография, альбом, событие, группа, страница, комментарий, история, видео, ссылка, примечание ... все, что имеет данные, является узлом.

Каждое отношение - это ребро от одного узла к другому. Публикуете ли вы фотографию, присоединяетесь ли к группе, например, к странице и т. д. Для этих отношений создается новое ребро.

# Объяснение

**Методы**:
- addEdge - добавить ребро в граф
- removeVertex - удалить вершину из графа, а также все рёбра, связанные с этой вершиной.
- removeEdge - удалить ребро между вершинами `u` и `v`
- printGraph - вывод графа в виде списка смежности
- hasEdge - проверить существует ли ребро между вершинами `u` и `v`
- DFS & startDFS - обход в глубину 
- BFS - обход в ширину
___
```cpp
std::unordered_map<int, std::list<int>> adjList;
```
Приватное поле adjList выступает в роли списка смежности. Здесь мы сохраняем граф в таком виде:
- ключ `std::unordered_map`- это вершина
- значение по этому ключу - это список смежных вершин, т.е. соседей

Такой вариант реализации позволяет быстро находить соседей любой вершины.

Граф с вершинами 1, 2 и 3, где есть рёбра (1 → 2), (1 → 3), будет представлен как:

```cpp
{
  1: [2, 3],
  2: [],
  3: []
}
```
___
```cpp
// Add new edge
void Graph::addEdge(int u, int v) {
    adjList[u].push_back(v); // Add edge u -> v
    if (!isDirected) {
        adjList[v].push_back(u); // Add a reverse edge v -> u if the graph is undirected
    }
}
```
Находим ключ `u` и добавляем по этому ключу значение `v`. Получаем ребро (U, V) Далее, если граф неориентированный, то добавляем связь и от `v` к `u`. Получаем (V, U).
___
```cpp
// Remove vertex
void Graph::removeVertex(int vertex) {
    adjList.erase(vertex); // Remove the vertex and all its outgoing connections
    for (auto& pair : adjList) {
        pair.second.remove(vertex); // Remove incoming links to this vertex
    }
}
```
Удаляем вершину, а также все связанные с ней ребра. В этом цикле:
```cpp
for (auto& pair : adjList) {
    pair.second.remove(vertex); // Remove incoming links to this vertex
}
```
мы ищем все ключи, значение которых - `vertex`, и удаляем их.
`pair.first` - это вершина (ключ). `pair.second` - список соседей (значение). `pair.second` — это сам список соседей для вершины `pair.first`. В строке `pair.second.remove(vertex)` выполняется операция удаления элемента vertex из этого списка.

Мы проходим по всем вершинам в графе (по ключам в `adjList`). Для каждой вершины (ключа `pair.first`) мы проверяем её список соседей (значение `pair.second`), и если среди соседей есть вершина `vertex`, то она будет удалена из этого списка с помощью метода `remove()`. 

Таким образом, этот цикл удаляет все ссылки на вершину `vertex` в качестве соседа других вершин. Это важно для удаления всех входящих рёбер для вершины `vertex`, то есть рёбер, где `vertex` является соседом для других вершин.

### Пример:

У нас есть граф:
```
A -- B -- C
|    |
v    v
D -- E
```
Если мы вызываем `removeVertex(E)`, то этот цикл будет работать следующим образом:

- Он удалит все вхождения E из списков соседей других вершин:
    - Из списка соседей для вершины B (поскольку E — это сосед вершины B).
    - Из списка соседей для вершины C (так как E также является соседом C).
___
```cpp
void Graph::removeEdge(int u, int v) {
    adjList[u].remove(v); // Remove edge u -> v
    if(!isDirect) {
        adjList[v].remove(u); // Remove edge v -> u (if graph is undirected)
    }
}
```
Здесь мы просто удаляем ребро между двумя вершинами. Первая строка сработает в любом случае, а вторая - только если граф неориентированный (или двунаправленный).
___
```cpp
// Print graph
void Graph::printGraph() const {
    for (const auto& pair : adjList) {
        std::cout << pair.first << " -> ";
        for (const auto& neighbor : pair.second) {
            std::cout << neighbor << " ";
        }
        std::cout << std::endl;
    }
}
```
Просто вывод графа в виде списка смежностей. Проходимся по каждой вершине `pair.second`, выводя ее, и для каждой выводим соседа. Между ними выводится `->`. 
___
```cpp
// Check for existence of edge
bool Graph::hasEdge(int u, int v) const {
    if (adjList.find(u) == adjList.end()) return false;
    for (int neighbor : adjList.at(u)) {
        if (neighbor == v) return true;
    }
    return false;
}
```
Сперва проверяем существует ли вершина `u`. Если нет - сразу же возвращаем `false`. Если вершина `u` существует, мы начинаем проверку всех её соседей. Для этого используем `adjList.at(u)`, который возвращает список всех соседей вершины `u` (то есть все вершины, с которыми есть рёбра из `u`). Мы перебираем все соседние вершины, хранящиеся в списке, с помощью цикла for.

В каждой итерации цикла проверяется, является ли текущий сосед вершины `u` равным вершине `v`. Если это так, значит существует ребро между вершинами `u` и `v`, и метод возвращает `true`, иначе вернется `false`.
___
```cpp
// Depth First Search (DFS)
void Graph::DFS(int start, std::unordered_map<int, bool>& visited) {
    visited[start] = true;
    std::cout << start << " ";

    for (int neighbor : adjList[start]) {
        if (!visited[neighbor]) {
            DFS(neighbor, visited);
        }
    }
}

void Graph::startDFS(int start) {
    std::unordered_map<int, bool> visited;
    for (const auto& pair : adjList) {
        visited[pair.first] = false; // Initialize visits
    }
    std::cout << "DFS: ";
    DFS(start, visited);
    std::cout << std::endl;
}
```
Метод `DFS`:
- Поиск в глубину. `start` - вершина, с которой начинается обход графа, `visited` - хэш-таблица, которая отслеживает, были ли посещены вершины. Это необходимо, чтобы избежать циклов и бесконечных рекурсий при обходе графа.
    ```cpp
    for (int neighbor : adjList[start]) {
        if (!visited[neighbor]) {
            DFS(neighbor, visited);
        }
    }
    ```
    Это рекурсивный обход соседей. Для каждой вершины в списке соседей текущей вершины (`adjList[start]`) проверяется, была ли она уже посещена (через хэш-таблицу `visited`). Если сосед не был посещен, вызывается рекурсивная функция DFS для этого соседа. Это приводит к повторному обходу графа из этой вершины.
    Таким образом, DFS углубляется в граф, пока не достигнет тупика (или вершины, которая не имеет непосещенных соседей).

Метод `startDFS`:
- Используется для запуска метода `DFS`. Он инициализирует процесс обхода и управляет состоянием посещенных вершин.
    ```cpp
    std::unordered_map<int, bool> visited;
    for (const auto& pair : adjList) {
        visited[pair.first] = false; // Initialize visits
    }
    ```
    Создается пустая хэш-таблица `visited`, которая будет отслеживать, посещена ли вершина.
    Мы проходим по всем вершинам графа (по ключам в `adjList`) и инициализируем их как непосещенные (значение `false`).
    Далее мы просто вызываем уже рассмотренный метод `DFS`, которому передаем `start` и только что созданную хэш-таблицу `visited`
___
```cpp
// Breadth First Search (BFS)
void Graph::BFS(int start) {
    std::unordered_map<int, bool> visited;
    for (const auto& pair : adjList) {
        visited[pair.first] = false;
    }

    std::list<int> queue;
    visited[start] = true;
    queue.push_back(start);

    std::cout << "BFS: ";
    while (!queue.empty()) {
        int current = queue.front();
        queue.pop_front();
        std::cout << current << " ";

        for (int neighbor : adjList[current]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                queue.push_back(neighbor);
            }
        }
    }
    std::cout << std::endl;
}
```
Обход в ширину. Так же есть начальная вершина `start` и хэш-таблица `visited`. В этих строчках:
```cpp
std::list<int> queue;
visited[start] = true;
queue.push_back(start);
```
создается пустая очередь, куда добавляется начальная вершина `start`.

Далее, пока очередь не пуста, мы проходимся циклом `while` по этой очереди и в каждой итерации извлекаем первую вершину из очереди. После этого она сразу же удаляется из очереди, а переменная, хранящая эту вершину, выводится в терминале. В этом же цикле проходимся по соседям и добавляем их в очередь для последующей обработки.

### Пошаговый пример работы алгоритма BFS

Рассмотрим граф:
```
1 — 2 — 3
|    \
4     5
```
Начнем BFS с вершины 1:

- Инициализация:

    - Очередь: [1]
    - Посещенные: {1}

- Обработка вершины 1:

    - Удаляем 1 из очереди (queue.pop_front()).
    Добавляем соседей (2 и 4) в очередь, если они еще не посещены (queue.push_back(neighbor)).
    
    - Очередь: [2, 4]
    - Посещенные: {1, 2, 4}

- Обработка вершины 2:

    - Удаляем 2 из очереди.
    Добавляем соседей (1, 3, 5). 1 уже посещена, добавляем только 3 и 5.
    - Очередь: [4, 3, 5]
    - Посещенные: {1, 2, 3, 4, 5}

- Обработка вершины 4:

    - Удаляем 4 из очереди.
    - Сосед 1 уже посещен.
    - Очередь: [3, 5]

- Обработка вершины 3:

    - Удаляем 3 из очереди.
    - Соседи 2 и 5 уже посещены.
    - Очередь: [5]

- Обработка вершины 5:

    - Удаляем 5 из очереди.
    - Сосед 2 уже посещен.
    - Очередь: []
